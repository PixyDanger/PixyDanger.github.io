C++ Console Application

Untitled Goose Chase

This program is a short text-based Dungeons and Dragons adventure. It has fifteen total endings, some of which are consistent, some of which will change based on a randomizer meant to mimic rolling a D20. The user can play through a story giving each playthrough a different name, they can view the playthroughs they have already completed, and clear the history when they want to start fresh.

Key Features

  • Modular story creation: The lead menu, lead, and scenario classes work together to build the story. They are built in such a way to make adding more options simple to make the program scalable and alterations easy.
  • User Interface specific class: With a focus make the program as user friendly as possible I made a UI class to have consistent means of outputing text to the terminal. This included creating a text wrapping feature so no words were cut off.
  • Menu and interface: The menu is simple for ease of use. It feature 4 numbered options and the user simply inputs the number matching the option they'd like to choose. There are also a yes and no options using y or n. Lastly, to keep the text from being overwhelming I added press enter to continue for longer text portions.

What I Learned

My largest challenge was losing the ability to use my primary computer in the middle of the process. This required me to do a deep dive into how use GitHub to retrieve my code and set everything up on a backup computer. There were a few simple steps I missed having not done so before, but I eventually got everything working again. I feel more confident about doing so in the future.
